# Discord Bot 

This is a discord bot than can generate events and take attendace for servers. It can also be used as a music bot to play off of YouTube.

## Run Locally

Clone the project

```bash
  git clone https://github.com/kevintran02/DiscordBot
```

Go to the project directory

```bash
  cd my-project
```

Install dependencies

```bash
  python -m pip install -r requirements.txt
```

Add the Bot to Your Server

```bash
  Done through the Discord Developer Portal

```

Run the Python Script

```bash
python main.py

```
